Unit 1: Propositional & Predicate Logic

Covers: Statements, truth values, connectives, tautologies, equivalences, duality, predicates, quantifiers, free/bound variables · Weightage: 18%

▸ Propositional Logic — Core Definitions
DEFProposition (Statement)

A sentence that is either completely TRUE or completely FALSE — never both, never "maybe". It must have a definite truth value.

Examples: "2+2=4" → Proposition ✓ | "x > 5" → NOT a proposition (x is unknown) | "Close the door" → NOT a proposition (command)
DEFLogical Connectives

Symbols used to join simple propositions to form compound statements. Each has a specific meaning and truth table.

¬p = NOT p (Negation — flips T to F, F to T) p ∧ q = p AND q (Conjunction — TRUE only when BOTH are true) p ∨ q = p OR q (Disjunction — FALSE only when BOTH are false) p → q = If p then q (Implication — FALSE only when p=T and q=F) p ↔ q = p iff q (Biconditional — TRUE when both have same value)
DEFTautology

A formula that is ALWAYS TRUE no matter what truth values you assign to its variables. Every row of its truth table gives TRUE.

p ∨ ¬p ≡ T (always true — "it rains OR it doesn't rain") (p → q) ↔ (¬p ∨ q) is a tautology
DEFContradiction

A formula that is ALWAYS FALSE no matter what values you assign. Every row of its truth table gives FALSE.

p ∧ ¬p ≡ F (always false — "it rains AND it doesn't rain")
DEFContingency

A formula that is SOMETIMES TRUE and SOMETIMES FALSE depending on values. It is neither a tautology nor a contradiction.

p ∧ q is contingent (true when both true, false otherwise)
DEFLogical Equivalence (≡)

Two formulas A and B are logically equivalent if they have EXACTLY THE SAME truth table — they give identical outputs for every possible input.

A ≡ B means A ↔ B is a tautology Key: p → q ≡ ¬p ∨ q (very important equivalence!)
DEFConverse, Inverse, Contrapositive of p → q

Three variations of an implication. The CONTRAPOSITIVE is always logically equivalent to the original. Converse and Inverse are equivalent to each other but NOT to the original.

Original: p → q Converse: q → p (NOT equivalent to original) Inverse: ¬p → ¬q (NOT equivalent to original) Contrapositive: ¬q → ¬p (EQUIVALENT to original ✓)
▸ Important Logical Laws & Equivalences
LAWDe Morgan's Laws

Used to "push" a NOT inside brackets. AND becomes OR and OR becomes AND when negated.

¬(p ∧ q) ≡ ¬p ∨ ¬q ¬(p ∨ q) ≡ ¬p ∧ ¬q
LAWDistributive Laws

AND distributes over OR, and OR distributes over AND — just like multiplication distributes over addition in algebra.

p ∧ (q ∨ r) ≡ (p ∧ q) ∨ (p ∧ r) p ∨ (q ∧ r) ≡ (p ∨ q) ∧ (p ∨ r)
LAWIdentity, Domination, Absorption & Idempotent Laws
Identity: p ∧ T ≡ p p ∨ F ≡ p Domination: p ∧ F ≡ F p ∨ T ≡ T Idempotent: p ∧ p ≡ p p ∨ p ≡ p Absorption: p ∨ (p ∧ q) ≡ p p ∧ (p ∨ q) ≡ p Double Neg: ¬(¬p) ≡ p
LAWDuality Law

If you swap ∧ ↔ ∨ and T ↔ F in a tautology, the result is also a tautology. Every logical law has a "dual" partner.

Dual of (p ∧ T ≡ p) is (p ∨ F ≡ p) Dual of (p ∧ ¬p ≡ F) is (p ∨ ¬p ≡ T)
▸ Predicate Logic
DEFPredicate

A statement CONTAINING A VARIABLE that becomes a proposition (true/false) once you substitute a specific value for the variable. Like a boolean function.

P(x): "x is even" P(4) = TRUE | P(3) = FALSE
DEFUniversal Quantifier — ∀ (For All)

∀x P(x) claims P(x) is TRUE for EVERY value of x in the domain. To prove it TRUE, show it holds for all. To prove it FALSE, find just ONE counterexample.

∀x P(x) = "For all x, P(x) is true" Disprove: find one x where P(x) is FALSE (counterexample)
DEFExistential Quantifier — ∃ (There Exists)

∃x P(x) claims P(x) is TRUE for AT LEAST ONE value of x. To prove it TRUE, find just one example. To prove FALSE, show no value works.

∃x P(x) = "There exists at least one x such that P(x) is true" Prove: find one x where P(x) is TRUE (example)
LAWNegation of Quantifiers

To negate a quantified statement: flip ∀ ↔ ∃ and negate the predicate. Think of it as switching between "all" and "some."

¬(∀x P(x)) ≡ ∃x ¬P(x) ("not all" = "some are not") ¬(∃x P(x)) ≡ ∀x ¬P(x) ("none" = "all are not")
DEFFree vs Bound Variables

A variable is BOUND if it is controlled/governed by a quantifier (∀ or ∃). A variable is FREE if no quantifier governs it — it acts like an unknown constant.

In ∃x P(x, y): x → BOUND (controlled by ∃) y → FREE (no quantifier governs it)

Unit 2: Set Theory, Counting & Recurrence Relations

Covers: Set operations, power set, inclusion-exclusion, permutations, combinations, Pigeonhole principle, recurrence relations · Weightage: 11%

▸ Set Theory — Core Definitions
DEFSet

An unordered collection of DISTINCT, well-defined objects called elements. Repetition is not allowed, and order doesn't matter.

A = {1, 2, 3} and A = {3, 1, 2} are the SAME set |A| = cardinality = number of elements in A
FORMULASet Operations

Standard ways to combine, compare, and build new sets from existing ones.

A ∪ B = Union = elements in A OR B (or both) A ∩ B = Intersection = elements in BOTH A and B A − B = Difference = elements in A but NOT in B A' = Complement = elements NOT in A (within universal set U) A × B = Cartesian = all ordered pairs (a,b), a∈A, b∈B A ⊕ B = Sym.Diff. = (A−B) ∪ (B−A) = elements in exactly one
FORMULAPower Set P(A)

The set of ALL possible subsets of A, including the empty set ∅ and A itself. For a set of size n, there are always 2ⁿ subsets.

|P(A)| = 2^|A| If A = {1, 2} → P(A) = {∅, {1}, {2}, {1,2}} → |P(A)| = 2² = 4
LAWDe Morgan's Laws (Sets)

Complement of a union = intersection of complements (and vice versa). Works exactly like De Morgan's in logic.

(A ∪ B)' = A' ∩ B' (A ∩ B)' = A' ∪ B'
LAWDistributive Laws (Sets)
A ∩ (B ∪ C) = (A ∩ B) ∪ (A ∩ C) A ∪ (B ∩ C) = (A ∪ B) ∩ (A ∪ C)
▸ Counting & Combinatorics
LAWAddition Principle

If task A can be done m ways and task B (separately) can be done n ways, then either A OR B can be done in m + n ways (when tasks are disjoint).

LAWMultiplication Principle

If task A can be done m ways AND THEN task B can be done n ways, then doing A followed by B can be done in m × n ways total.

FORMULAPermutation ⁿPᵣ — Order Matters

Number of ways to ARRANGE r items chosen from n items, where ORDER MATTERS. Choosing a president, VP, and secretary from 10 people uses permutations.

ⁿPᵣ = n! / (n−r)! = n × (n−1) × (n−2) × ... × (n−r+1) ⁵P₃ = 5×4×3 = 60
FORMULACombination ⁿCᵣ — Order Doesn't Matter

Number of ways to SELECT r items from n items where ORDER DOESN'T MATTER. Choosing a committee of 3 from 10 people uses combinations.

ⁿCᵣ = C(n,r) = n! / (r! × (n−r)!) Key relation: ⁿPᵣ = r! × ⁿCᵣ C(n,r) = C(n, n−r) (symmetry property) C(n,0) = C(n,n) = 1
THMBinomial Theorem

Expands (x + y)ⁿ into a sum without multiplying n times. Each term uses a binomial coefficient C(n,k).

(x + y)ⁿ = Σₖ₌₀ⁿ C(n,k) · x^(n−k) · y^k (x+y)² = C(2,0)x² + C(2,1)xy + C(2,2)y² = x² + 2xy + y²

Pascal's Triangle gives the coefficients C(n,k) row by row

THMPigeonhole Principle

If you place MORE items than containers, at least one container MUST hold more than one item. Simple but surprisingly useful in proofs.

Basic: If n items → k boxes and n > k, ∃ box with ≥ 2 items Generalized: At least one box contains ≥ ⌈n/k⌉ items Example: 13 people must include 2 born in the same month (12 months)
FORMULAInclusion-Exclusion Principle

To count elements in a UNION without double-counting overlaps: add individuals, subtract pairwise overlaps, add back triple overlaps, etc.

|A ∪ B| = |A| + |B| − |A ∩ B| |A ∪ B ∪ C| = |A| + |B| + |C| − |A∩B| − |B∩C| − |A∩C| + |A∩B∩C|
▸ Recurrence Relations
DEFRecurrence Relation

An equation where each term is defined using one or more PREVIOUS terms, plus initial conditions to start the sequence. Like a recipe where each step builds on earlier steps.

Fibonacci: aₙ = aₙ₋₁ + aₙ₋₂, a₀ = 0, a₁ = 1 Gives: 0, 1, 1, 2, 3, 5, 8, 13, 21, ...
FORMULACharacteristic Equation Method (Homogeneous)

To solve linear homogeneous recurrence relations, substitute aₙ = rⁿ to get the characteristic equation, find its roots, then use initial conditions to find constants.

For aₙ = c₁aₙ₋₁ + c₂aₙ₋₂ (2nd order): Characteristic equation: r² − c₁r − c₂ = 0 Case 1 — Distinct roots r₁ ≠ r₂: aₙ = A·r₁ⁿ + B·r₂ⁿ Case 2 — Repeated root r₁ = r₂ = r: aₙ = (A + Bn)·rⁿ Use initial conditions a₀, a₁ to find A and B
FORMULANon-Homogeneous Recurrence (Undetermined Coefficients)

When the recurrence has an extra term (like a constant or exponential on the right side), find the homogeneous solution + a particular solution and add them.

For aₙ − c·aₙ₋₁ = f(n): General solution = Homogeneous solution + Particular solution If f(n) = constant k: try particular solution aₙ = A (constant) If f(n) = bⁿ: try particular solution aₙ = C·bⁿ

Unit 3: Functions & Algebraic Structures

Covers: Domain, range, injective, surjective, bijective, composition, inverse functions. Semigroup, Monoid, Group, Subgroup, Coset, Normal Subgroup, Lagrange's Theorem, Ring, Field · Weightage: 22%

▸ Functions — Definitions
DEFFunction (Mapping) f: A → B

A rule that assigns EXACTLY ONE output (element of B) to every input (element of A). Domain = set A; Codomain = set B; Range = actual output values used.

Domain A: all possible inputs Codomain B: all possible outputs (declared) Range: {f(a) : a ∈ A} ⊆ B (actual outputs)
DEFInjective (One-to-One) Function

Different inputs ALWAYS produce different outputs — no two elements of A ever map to the same element of B. Like a "no-sharing" rule for outputs.

f is injective iff: f(a₁) = f(a₂) ⟹ a₁ = a₂ Equivalently: a₁ ≠ a₂ ⟹ f(a₁) ≠ f(a₂)
DEFSurjective (Onto) Function

Every element in codomain B is "hit" by at least one input from A. Nothing in B is left out — the range equals the codomain.

f is surjective iff: ∀ b ∈ B, ∃ a ∈ A such that f(a) = b Range = Codomain B
DEFBijective (One-to-One and Onto)

BOTH injective AND surjective — a perfect pairing where every input has a unique output AND every output is covered. Only bijective functions have inverse functions.

Bijective = Injective + Surjective Perfect 1-to-1 correspondence between A and B |A| = |B| is necessary for bijection between finite sets
FORMULAComposition of Functions (f ∘ g)

Apply g FIRST, then apply f to the result. Like chaining two machines — output of first becomes input of second.

(f ∘ g)(x) = f(g(x)) — apply g first, then f (g ∘ f)(x) = g(f(x)) — apply f first, then g IMPORTANT: f ∘ g ≠ g ∘ f in general (order matters!)
FORMULAInverse Function f⁻¹

The reverse operation that undoes what f did. Exists ONLY if f is bijective. Swaps input and output roles.

f⁻¹ exists ⟺ f is bijective f(f⁻¹(y)) = y and f⁻¹(f(x)) = x To find f⁻¹: write y = f(x), solve for x in terms of y
▸ Algebraic Structures — The Hierarchy
DEFBinary Operation

A rule that combines TWO elements from a set and produces ONE result from the SAME set (closure property). Addition on ℤ is a binary operation; division on ℤ is NOT (2÷3 ∉ ℤ).

∗: S × S → S (closure: a∗b ∈ S for all a,b ∈ S)
DEFSemigroup (S, ∗)

The simplest algebraic structure. Just needs CLOSURE and ASSOCIATIVITY. No identity element, no inverse required.

Axioms: 1. Closure: a∗b ∈ S for all a,b ∈ S 2. Associativity: (a∗b)∗c = a∗(b∗c) for all a,b,c ∈ S Example: (ℤ⁺, ×) — positive integers under multiplication
DEFMonoid (S, ∗)

A semigroup PLUS an identity element e. The identity element doesn't change anything when combined: a∗e = e∗a = a.

Axioms: Semigroup axioms + 3. Identity: ∃ e ∈ S such that a∗e = e∗a = a for all a ∈ S Example: (ℤ, ×) — integers under multiplication, identity = 1
DEFGroup (G, ∗)

A monoid where every element also has an INVERSE. The inverse of a "undoes" the operation. Groups are the foundation of modern algebra.

Axioms: Monoid axioms + 4. Inverse: ∀ a ∈ G, ∃ a⁻¹ ∈ G such that a∗a⁻¹ = a⁻¹∗a = e Example: (ℤ, +) — integers under addition, identity=0, inverse of a is −a
DEFAbelian (Commutative) Group

A group where the ORDER of operation doesn't matter — a∗b = b∗a always. Like addition: 3+5 = 5+3.

Abelian Group = Group + Commutativity 5. Commutativity: a∗b = b∗a for all a,b ∈ G
DEFSubgroup (H, ∗)

A NON-EMPTY SUBSET H of group G that is itself a group under the same operation. Must contain the identity, be closed, and contain inverses.

H ≤ G (H is a subgroup of G) iff: 1. e ∈ H (contains identity) 2. a,b ∈ H ⟹ a∗b ∈ H (closed under operation) 3. a ∈ H ⟹ a⁻¹ ∈ H (closed under inverses)
THMLagrange's Theorem

The size (order) of any subgroup MUST DIVIDE the size of the whole group. You cannot have a subgroup of size 4 inside a group of size 6, since 4 does not divide 6.

If H is a subgroup of finite group G, then: |H| divides |G| Number of distinct cosets of H in G = |G| / |H| (index)
DEFCoset

When you "shift" a subgroup H by a fixed element a, you get a coset. Left coset = aH (multiply from left), Right coset = Ha (multiply from right).

Left coset: aH = {a∗h : h ∈ H} Right coset: Ha = {h∗a : h ∈ H} Cosets of H partition G into equal-sized disjoint pieces
DEFNormal Subgroup

A subgroup H where LEFT cosets and RIGHT cosets are ALWAYS EQUAL for every element of G. Every subgroup of an abelian group is normal.

H is normal in G (written H ◁ G) iff: aH = Ha for ALL a ∈ G Equivalently: aHa⁻¹ = H for all a ∈ G
DEFHomomorphism

A function between two groups that PRESERVES the group operation — doing the operation then mapping = mapping then doing the operation.

f: (G,∗) → (H,•) is homomorphism iff: f(a∗b) = f(a)•f(b) for all a,b ∈ G Properties: f(e_G) = e_H and f(a⁻¹) = [f(a)]⁻¹
DEFCyclic Group

A group where ALL elements can be generated by repeatedly applying the operation to a single element g (called the generator).

G = ⟨g⟩ = {gⁿ : n ∈ ℤ} = {..., g⁻², g⁻¹, e, g, g², ...} Every cyclic group is abelian Example: (ℤ₆, +₆) is cyclic, generators are 1 and 5
▸ Rings, Integral Domains & Fields
DEFRing (R, +, ·)

A set with TWO operations (addition and multiplication) satisfying: (R,+) is an abelian group, multiplication is associative, and multiplication distributes over addition.

Ring axioms: • (R, +) is an abelian group (identity = 0, inverse = −a) • Multiplication is associative: a·(b·c) = (a·b)·c • Distributivity: a·(b+c) = a·b + a·c and (b+c)·a = b·a + c·a Example: (ℤ, +, ×), (ℤₙ, +ₙ, ×ₙ)
DEFIntegral Domain

A COMMUTATIVE ring with identity (1≠0) that has NO zero divisors — if a·b = 0, then a = 0 or b = 0. Like the integers.

Integral Domain = Commutative Ring + No zero divisors Example: (ℤ, +, ×) is an integral domain Non-example: ℤ₆ is NOT (2·3 = 0 mod 6, but 2≠0, 3≠0)
DEFField

An integral domain where EVERY non-zero element has a multiplicative inverse. Division is always possible (except by zero).

Field = Integral Domain + multiplicative inverse for every a ≠ 0 Hierarchy: Field ⊂ Integral Domain ⊂ Ring Examples: ℚ (rationals), ℝ (reals), ℂ (complex), ℤₚ (p prime)

Unit 4: Relations, Partial Orders & Lattices

Covers: Binary relations, properties, equivalence relations, partial orders, Hasse diagrams, LUB, GLB, lattices, Boolean algebra · Weightage: 22%

▸ Relations — Definitions & Properties
DEFBinary Relation R on Set A

A subset of A × A. It tells us which pairs of elements are "related." We write aRb (or (a,b) ∈ R) if a is related to b.

R ⊆ A × A aRb means (a,b) ∈ R (a is related to b)
DEFReflexive

Every element is related to ITSELF. The diagonal of the relation matrix is all 1s.

R is reflexive iff: (a,a) ∈ R for ALL a ∈ A Example: "≤" on ℤ is reflexive (a ≤ a always)
DEFSymmetric

If a is related to b, then b is ALSO related to a. The relation matrix is symmetric about the diagonal.

R is symmetric iff: (a,b) ∈ R ⟹ (b,a) ∈ R Example: "is a sibling of" is symmetric
DEFAntisymmetric

If a is related to b AND b is related to a, then a MUST EQUAL b. This is NOT the same as "not symmetric."

R is antisymmetric iff: (a,b)∈R and (b,a)∈R ⟹ a = b Example: "divides" on ℕ — if a|b and b|a, then a=b
DEFTransitive

If a is related to b, and b is related to c, then a MUST be related to c. Chains are automatically connected.

R is transitive iff: (a,b)∈R and (b,c)∈R ⟹ (a,c)∈R Example: "is an ancestor of" is transitive
DEFEquivalence Relation

A relation that is ALL THREE: Reflexive + Symmetric + Transitive. Partitions the set into "equivalence classes" — elements in same class are considered equivalent.

Equivalence Relation = Reflexive + Symmetric + Transitive Example: congruence mod m: a ≡ b (mod m) iff m | (a−b) Equivalence classes of ≡ mod 3: [0]={...,−3,0,3,...}, [1]={...,−2,1,4,...}, [2]={...,−1,2,5,...}
DEFCompatibility Relation & Maximal Compatibility Block

A relation that is Reflexive and Symmetric (but not necessarily transitive). A Maximal Compatibility Block is the largest set of mutually compatible elements.

FORMULAComposite Relation R∘S

The composition of relations: aR∘Sc means there exists b such that aRb AND bSc. Like function composition but for relations.

R∘S = {(a,c) : ∃b such that (a,b)∈R and (b,c)∈S} Matrix: M_{R∘S} = M_R × M_S (Boolean matrix multiplication)
FORMULAWarshall's Algorithm — Transitive Closure

Computes the path matrix (reachability matrix) from an adjacency matrix. Checks whether a path exists between every pair of vertices by considering each vertex as an intermediate step.

Input: Adjacency matrix W of relation R on {1,2,...,n} Algorithm: For k = 1 to n: For i = 1 to n: For j = 1 to n: W[i][j] = W[i][j] OR (W[i][k] AND W[k][j]) Result W = path matrix (transitive closure)

W[i][j] = 1 means there is a path from vertex i to vertex j of any length

▸ Partial Orders, Posets & Hasse Diagrams
DEFPartial Order & Poset

A relation that is Reflexive + Antisymmetric + Transitive. Not all elements need to be comparable — some may be "incomparable" (neither a ≤ b nor b ≤ a).

Partial Order = Reflexive + Antisymmetric + Transitive (A, ≤) = Partially Ordered Set (Poset) Example: (P(A), ⊆) — power set ordered by inclusion
DEFHasse Diagram

A simplified visual of a partial order. Elements are dots; lines go UP to show "greater than." Reflexive loops and transitive edges are omitted (implied).

Rules for drawing Hasse diagram: 1. Place higher elements above lower elements 2. Draw a line from a to b if a ≺ b directly (no element between them) 3. Remove reflexive loops (a→a) 4. Remove edges implied by transitivity
DEFMaximal vs Greatest Element

MAXIMAL: no element is greater than it, but it may not be comparable to everything. GREATEST: ALL other elements are ≤ it. Greatest element is unique; maximal elements can be many.

Greatest element g: a ≤ g for ALL a in poset (unique if exists) Maximal element m: there is no x with m < x (may be multiple) Least element l: l ≤ a for ALL a in poset (unique if exists) Minimal element: there is no x with x < m
DEFLUB (Supremum) & GLB (Infimum)

For a subset S of a poset: LUB = smallest element that is ≥ ALL elements of S. GLB = largest element that is ≤ ALL elements of S.

LUB(S) = Supremum = Least Upper Bound (join ∨) GLB(S) = Infimum = Greatest Lower Bound (meet ∧) These may or may not exist in a general poset
▸ Lattices
DEFLattice

A poset where EVERY PAIR of elements has both a LUB (join, ∨) AND a GLB (meet, ∧). Every two elements can always be "joined" or "met."

⟨L, ≤⟩ is a lattice iff for every a,b ∈ L: a ∨ b (join = LUB of {a,b}) exists AND a ∧ b (meet = GLB of {a,b}) exists
LAWLaws of Lattice (Properties)
Idempotent: a ∨ a = a a ∧ a = a Commutative: a ∨ b = b ∨ a a ∧ b = b ∧ a Associative: (a∨b)∨c = a∨(b∨c) Absorption: a ∨ (a ∧ b) = a a ∧ (a ∨ b) = a
THMLattice Inequalities (Exam Favourite!)

Two key inequalities that hold in EVERY lattice. Equality holds only in distributive lattices.

a ∧ (b ∨ c) ≥ (a ∧ b) ∨ (a ∧ c) a ∨ (b ∧ c) ≤ (a ∨ b) ∧ (a ∨ c)

Exam tip: If a,b,c ∈ L and a ≤ b, then a ∨ c ≤ b ∨ c and a ∧ c ≤ b ∧ c

DEFDistributive Lattice

A lattice where join distributes over meet and meet distributes over join — BOTH distributive laws hold perfectly as equalities.

a ∧ (b ∨ c) = (a ∧ b) ∨ (a ∧ c) a ∨ (b ∧ c) = (a ∨ b) ∧ (a ∨ c)
DEFComplemented Lattice

A BOUNDED lattice (has a 0 = least element, and 1 = greatest element) where every element a has a COMPLEMENT a' such that a∨a'=1 and a∧a'=0.

a ∨ a' = 1 (top/greatest element) a ∧ a' = 0 (bottom/least element) a' is called the complement of a
DEFBoolean Algebra (Boolean Lattice)

A lattice that is BOTH distributive AND complemented. The most structured type — models true/false logic and set operations perfectly.

Boolean Algebra = Distributive Lattice + Complemented Lattice Example 1: Power set P(A) with ∪, ∩, complement Example 2: {0,1} with OR, AND, NOT (classic logic) S₃₀ = divisors of 30 under divisibility forms a Boolean algebra

▸ Graph Theory — Basic Definitions
DEFGraph G = (V, E)

A mathematical structure with VERTICES (nodes/dots) and EDGES (lines connecting pairs of vertices). Models real-world networks like roads, social connections, circuits.

V = set of vertices (nodes) E = set of edges (connections) Order of G = |V| (number of vertices) Size of G = |E| (number of edges)
DEFDegree of a Vertex

The number of EDGES touching (incident to) a vertex. In directed graphs, in-degree = edges coming IN, out-degree = edges going OUT.

Undirected: deg(v) = number of edges at v Directed: in-deg(v) = edges pointing TO v out-deg(v) = edges pointing FROM v Isolated vertex: deg(v) = 0 Pendant vertex: deg(v) = 1
THMHandshaking Lemma

Sum of ALL vertex degrees = TWICE the number of edges. Every edge adds 1 to the degree of each of its two endpoints. Consequence: odd-degree vertices always come in pairs.

Σ deg(v) = 2|E| (sum over all vertices v) Consequence: Every graph has an EVEN number of odd-degree vertices Corollary: An r-regular graph with n vertices has n·r/2 edges
FORMULAComplete Graph Kₙ

Every vertex is connected to every OTHER vertex. Has the maximum possible number of edges for n vertices. K₅ is famous in planarity theory.

Number of edges: |E| = C(n,2) = n(n−1)/2 Degree of each vertex: deg(v) = n−1 Kₙ is (n−1)-regular K₁=1 edge:0 | K₂=1 | K₃=3 | K₄=6 | K₅=10 | Kₙ=n(n−1)/2
DEFComplete Bipartite Graph Kₘ,ₙ

Vertices split into two groups V₁ (size m) and V₂ (size n). EVERY vertex in V₁ is connected to EVERY vertex in V₂ (no edges within a group).

|E| = m × n deg(v) = n for v ∈ V₁; deg(v) = m for v ∈ V₂ Kₘ,ₙ is regular iff m = n (then it is m-regular)
DEFTypes of Graphs
Simple graph: no loops, no parallel edges Multigraph: parallel edges allowed Pseudograph: loops and parallel edges allowed Digraph: directed edges (arrows) Weighted graph: edges have weights/costs Null graph: no edges (only isolated vertices) Regular graph: all vertices have same degree
DEFWalk, Path, Simple Path, Elementary Path

Different levels of restriction on how we travel through a graph. Elementary is most restrictive (no repeated vertices), walk is least restrictive (everything allowed).

Walk: any sequence of vertices connected by edges (can repeat) Simple Path: no repeated EDGES Elementary Path: no repeated VERTICES (also called just "path") Cycle/Circuit: starts and ends at same vertex
DEFEuler Path & Euler Circuit

Euler Path: traverses every EDGE exactly once. Euler Circuit: an Euler path that starts and ends at the same vertex. Based on vertex degrees.

Euler Circuit exists iff: • Graph is connected AND • Every vertex has EVEN degree Euler Path (not circuit) exists iff: • Graph is connected AND • Exactly 2 vertices have ODD degree (start and end at those)
DEFIsomorphic Graphs

Two graphs are isomorphic if one can be RELABELLED to look exactly like the other. Same structure, different names. Check: same vertex count, edge count, degree sequence.

Necessary conditions (not sufficient) for isomorphism: 1. Same number of vertices: |V₁| = |V₂| 2. Same number of edges: |E₁| = |E₂| 3. Same degree sequence (sorted list of all degrees) 4. Same number of cycles of each length
▸ Connectivity, Reachability & Matrices
DEFStrongly / Weakly / Unilaterally Connected

For DIRECTED graphs (digraphs): Strongly = paths in BOTH directions between every pair. Weakly = connected ignoring edge directions. Unilaterally = at least one direction between every pair.

Strongly connected: path u→v AND path v→u for ALL pairs (u,v) Unilaterally connected: path u→v OR path v→u for ALL pairs Weakly connected: connected when edge directions are ignored
DEFAdjacency Matrix

An n×n matrix where A[i][j] = 1 if there's an edge from i to j, else 0. Powers of the matrix count paths of that length.

A[i][j] = 1 if edge (i,j) exists, else 0 Undirected: A is symmetric (A = Aᵀ) (Aⁿ)[i][j] = number of walks of length n from vertex i to j Sum of row i = out-degree of vertex i (in digraph)
DEFPath (Reachability) Matrix & Node Base

Path matrix P[i][j] = 1 if ANY path exists from vertex i to vertex j. Node base = minimal set of vertices from which ALL other vertices are reachable.

Path matrix = result of Warshall's algorithm on adjacency matrix Reachable set of v = {u : there is a path from v to u} Node base = minimal set B such that every vertex is reachable from B
▸ Trees
DEFTree

A CONNECTED undirected graph with NO CYCLES. It is the minimally connected graph — remove any edge and it disconnects; add any edge and it creates a cycle.

Tree with n vertices has exactly n−1 edges Equivalent conditions (any one implies tree): • Connected + no cycles • Connected + n−1 edges • No cycles + n−1 edges • Unique path between every pair of vertices
DEFRooted Tree — Terminology
Root: top-most node (no parent) Parent: immediate ancestor of a node Children: immediate descendants of a node Leaf: node with no children (terminal node) Internal node: node with at least one child Level of node: length of path from root to node Height of tree: maximum level of any leaf
DEFBinary Tree & Full Binary Tree

Binary tree: each node has at most 2 children (left and right). Full (complete) binary tree: every node has EXACTLY 0 or 2 children.

Binary tree with n levels: maximum nodes = 2ⁿ − 1 Full binary tree with i internal nodes: Leaves l = i + 1 (leaves = internal nodes + 1) Total nodes = 2i + 1
DEFm-ary Tree

Each node has at most m children. For a FULL m-ary tree (every internal node has exactly m children):

Full m-ary tree: If i = number of internal nodes: l = leaves = i(m−1) + 1 n = total nodes = mi + 1 = im + 1 Full ternary tree (m=3) with n levels: max nodes = (3ⁿ−1)/2
FORMULATree Traversals (Pre-order, In-order, Post-order)

Three systematic methods to visit ALL nodes of a rooted binary tree exactly once, differing only in WHEN the root is visited relative to its subtrees.

Pre-order (Root → Left → Right): visit root BEFORE subtrees 1. Visit root 2. Traverse left subtree 3. Traverse right subtree In-order (Left → Root → Right): visit root BETWEEN subtrees 1. Traverse left subtree 2. Visit root 3. Traverse right subtree Post-order (Left → Right → Root): visit root AFTER subtrees 1. Traverse left subtree 2. Traverse right subtree 3. Visit root

In-order traversal of a Binary Search Tree gives elements in SORTED order!

▸ Graph Algorithms
FORMULABFS — Breadth-First Search

Explores graph LEVEL BY LEVEL using a QUEUE. Visits all neighbors of a vertex before going deeper. Finds SHORTEST PATH in unweighted graphs.

Algorithm: 1. Start at source vertex s, mark as visited, add to queue 2. While queue is not empty: a. Dequeue vertex u b. For each unvisited neighbor v of u: - Mark v as visited - Record parent[v] = u, dist[v] = dist[u] + 1 - Enqueue v Time complexity: O(V + E)
FORMULADFS — Depth-First Search

Explores as DEEP as possible before backtracking, using a STACK (or recursion). Used for cycle detection, topological sort, strongly connected components.

Algorithm (recursive): DFS(v): Mark v as visited For each unvisited neighbor u of v: DFS(u) Time complexity: O(V + E)
FORMULADijkstra's Algorithm — Shortest Path

Finds the SHORTEST PATH from a source vertex to all others in a WEIGHTED graph with NON-NEGATIVE weights. Greedy approach — always pick closest unvisited vertex.

Algorithm: 1. dist[source] = 0; dist[all others] = ∞; visited = {} 2. Repeat until all visited: a. Pick unvisited vertex u with minimum dist[u] b. Mark u as visited c. For each neighbor v of u: If dist[u] + weight(u,v) < dist[v]: dist[v] = dist[u] + weight(u,v) ← RELAX the edge Time complexity: O(V²) or O(E log V) with priority queue

Does NOT work for negative weight edges!

FORMULAKruskal's Algorithm — Minimum Spanning Tree

Finds the spanning tree connecting all vertices with MINIMUM TOTAL EDGE WEIGHT. Sort edges by weight and greedily add the cheapest edge that doesn't create a cycle.

Algorithm: 1. Sort ALL edges by weight (ascending) 2. Initialize each vertex as its own component (DSU) 3. For each edge (u,v) in sorted order: If u and v are in DIFFERENT components: Add edge to MST Merge the two components 4. Stop when MST has n−1 edges Result: Minimum Spanning Tree with n−1 edges, minimum total weight
FORMULAWarshall's Algorithm — Path Matrix

Computes the reachability (path) matrix from the adjacency matrix. After running, W[i][j]=1 means vertex j is reachable from vertex i.

Input: Adjacency matrix W[n×n] of a digraph Algorithm: For k = 1 to n: For i = 1 to n: For j = 1 to n: W[i][j] = W[i][j] OR (W[i][k] AND W[k][j]) Output: W = Path (Reachability) Matrix
